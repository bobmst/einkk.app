# 玩家测试方案（S42）

目标：在 S42 开打前和开打期间，用少量玩家把网站从看预测到填数据的每一步都走一遍，确认它可以正式公开。赛季结束后的 Tally 问卷也顺带验一遍。

- **测试员**：4–6 人，最好每人负责不同的服务器和语言，下面有分配表。
- **测试站**：
  - 赛前用**预览站** https://uat.einkk.app （rehearsal，模拟赛季，页面顶部有黄色横幅），随便填，不会进正式数据；
  - 开打后用 **https://einkk.app**，填真实数据。

## 时间线

| 阶段 | 时间（JST） | 站点 | 谁做什么 |
|---|---|---|---|
| 0 准备 | 10/12–10/13 | 预览站 | 运营：开模拟赛季，把它推进到"开催中"，把链接和本文的「测试员任务」发给测试员 |
| 1 彩排 | 10/13–10/14 | 预览站 | 测试员：做完 A–F 全部任务，反馈问题 |
| 修复 | 10/14 | — | 运营：修阻断性问题，合并 |
| 2 正式 | 10/15 12:00 – 10/22 04:59 | einkk.app | 测试员：每天至少报一次真实数据（任务 G）；运营：每天核对（运营检查表） |
| 3 赛后 | 10/22 05:00 起 | einkk.app + Tally | 测试员：看结束状态，填 Tally 问卷（任务 H） |

## 测试员分配

覆盖的维度：6 个服务器、6 种语言、手机/电脑、iOS/Android、深色/浅色。每人填自己真实的服务器，语言和设备按下表分。

| 测试员 | 服务器 | 界面语言 | 主设备 | 第二设备 |
|---|---|---|---|---|
| T1 | JP | 日本語 | iPhone Safari | 电脑 Chrome |
| T2 | GLOBAL / NA | English | Android Chrome | 电脑 Edge/Firefox |
| T3 | TW-HK | 繁體中文 | iPhone | — |
| T4 | KR | 한국어 | Android | — |
| T5 | SEA | English / Español | 电脑 | 手机 |
| T6（运营自己） | 任意 | 简体中文 | 电脑 | 手机 |

人数不够时，一人可以兼两种语言（切换后把 A、B 再看一遍）。

## 反馈方式

每个问题一条，写清楚以下几项（任务编号让问题能对上号）：

1. 任务编号（如 `E3`）
2. 服务器 / 语言 / 设备和浏览器
3. 看到了什么，期望是什么
4. 截图（手机长截图最好）

渠道用 Discord 的测试频道或共享表格就行。有 GitHub 账号的也可以直接用页面底部的「Report a problem」开 issue。

## 测试员任务

> 发给测试员时，可以只发这一节。预览站顶部有黄色"Rehearsal"横幅，上面的数字全是假的，可以随便填。

### A. 第一次打开

| # | 操作 | 期望 |
|---|---|---|
| A1 | 用手机打开链接 | 3 秒内出现内容；页面不需要左右滑动 |
| A2 | 看语言 | 自动用手机的系统语言（日/韩/简/繁/西，其他为英文） |
| A3 | 点右上角语言按钮，切到另一种语言再切回来 | 全页文字都变；刷新后保持你选的语言 |
| A4 | 点亮/暗切换 | 两种模式下文字、图表都看得清 |
| A5 | 顶部服务器标签切到你的服务器 | 往下滚时标签栏一直固定在顶部；刷新后仍记住你的服务器 |

### B. 赛季卡片

| # | 操作 | 期望 |
|---|---|---|
| B1 | 看 Boss 名、属性、弱点 | 和游戏里一致 |
| B2 | 看开始/结束时间 | 显示的是你所在地区的当地时间；和游戏里的结束时间对得上 |
| B3 | 看倒计时 | 「距离结束」的时间合理，过一分钟会变 |

### C. 预测（3% 分数线）

| # | 操作 | 期望 |
|---|---|---|
| C1 | 看「最终 3% 分数线」卡片 | 有一个预测数字和区间；能看懂"第几天"和"几分钟前更新" |
| C2 | 看分档切片：点不同的档位（1% / 3% / 5%…） | 曲线、"最可能""九成在…之间"跟着变 |
| C3 | 一句话说说：这块你看懂了吗？哪句话看不懂？ | （主观反馈，最重要） |

### D. 伤害排名表与"我的伤害在哪一档"

| # | 操作 | 期望 |
|---|---|---|
| D1 | 看曲线和表格 | 档位从高到低排列；带「~」的格子有说明 |
| D2 | 在「我的伤害」框输入你当前的伤害（全部位数） | 自动加千分位逗号；显示"约前 x%"；曲线上出现"你"的标记 |
| D3 | 输入一个很高（比第一名还高）和一个很低的数 | 标记贴在图边缘并有 ↑/↓，文字说"高于/低于某档" |
| D4 | 输入后看上面的档位按钮和表格高亮 | 自动切到你所在的档，并显示"你的分数进前 x% 的概率" |

### E. 填写数据（核心）

用你的**真实**游戏画面填（预览站阶段数字可以随便编）。

| # | 操作 | 期望 |
|---|---|---|
| E1 | 打开「回报分数 / データ提供」表单，选服务器 | 默认是你在顶部选的服务器 |
| E2 | 伤害照游戏里的数字全部位数输入 | 下方显示换算后的值，提醒你核对位数 |
| E3 | 故意输入一个结尾 000 的数 | 出现"不要四舍五入"的黄色提示 |
| E4 | 排名显示选「百分比」，填 `3.00` | 可以下一步。再试填 `0.05`，应有黄色提醒（不常见） |
| E5 | 排名显示选「名次」，填 `25` | 可以下一步。填 `250` 应不能继续（只有前 200 显示名次） |
| E6 | 「读取时间」 | 默认是现在，可以改 |
| E7 | 下一步 → 核对页 | 显示的内容和你填的一致；出现人机验证（通常自动通过） |
| E8 | 提交 | 显示"已收到"。点「再报一个」能填第二条 |
| E9 | 在手机上做一遍 E1–E8 | 键盘类型合适（数字键盘），按钮不被键盘挡住 |

把每次提交的时间、伤害、排名记下来，运营要用来核对。

### F. 往届成绩

| # | 操作 | 期望 |
|---|---|---|
| F1 | 滚到「往届成绩」 | 每季的预测、实际 3%、误差都有；颜色能区分命中/未命中 |
| F2 | 换个服务器再看 | 内容随服务器变化 |

### G. 正式赛季（10/15–10/22，einkk.app）

| # | 操作 | 期望 |
|---|---|---|
| G1 | 每天打完后报一次真实数据（重复 E 的流程） | 每次都提交成功 |
| G2 | 每天看一次预测 | 「更新时间」在近 1 小时内；数字变化合理 |
| G3 | 最后一天（10/21 晚）再报一次 | 越接近结束的数据越有用 |

### H. 赛后（10/22 05:00 起）

| # | 操作 | 期望 |
|---|---|---|
| H1 | 打开网站 | 状态显示"已结束·最终分数线统计中"；数据表单关闭并说明原因 |
| H2 | 点卡片上的赛季问卷链接 | 打开 Tally 问卷，语言可选 |
| H3 | 填最终伤害和排名提交 | 成功；填错格式时有提示 |

## 运营检查表

- [ ] 合并 #17（文案）、#18（域名）；在 Turnstile 控件的 Hostname 里加 `einkk.app`

- [ ] 自己先把 A–F 走一遍，再发给测试员

### 阶段 1（彩排期间）

- [ ] 测试员提交后，`einkk-inbox-dev` 里有对应的行（时间、伤害、排名对得上）
- [ ] `ops.rehearsal run`：日志显示读到了这些回报，指纹变化后发布了新的 revision
- [ ] 在 GUI 里推进到第 2、3、4 天（填 n2–n4），预览站的路线依次是 chain|1/2/3 → router，区间变窄
- [ ] 推进到结束：页面变为结束状态，表单关闭
- [ ] 汇总反馈，标出阻断项

### 阶段 2（正式赛季，每天）

- [ ] 05:02 的日常运行和开打后的定时运行正常（Actions 全绿）
- [ ] 每天 X 上的 n 值录入后，几分钟内页面更新
- [ ] `einkk-inbox` 里当天的回报数量；抽查测试员记下的提交是否都在
- [ ] 第一天：在正式站真实提交一次（#15 清单），确认通过后从 `einkk-inbox` 删除那一行
- [ ] 有没有可疑数据（同一伤害大量重复、明显错位数）

### 阶段 3（赛后）

- [ ] 填 n5 → Tally 问卷自动开放；卡片上的问卷链接出现
- [ ] `--sync-all` 导入问卷；历史表 S42 有实际值和误差
- [ ] 清理彩排数据：`python -m ops.rehearsal clean --yes`
